# Friday 设计语言

## 1. 设计原则

| 原则 | 含义 | 在 Friday 中的体现 |
|------|------|-------------------|
| **信息密度优先** | 开发者需要高效获取信息，不做无意义留白 | 诊断步骤紧凑排列，工具输出折叠/展开可控，日志默认紧凑视图 |
| **状态即视觉** | 系统状态通过颜色和图标一目了然 | 绿=运行中/正常，黄=需确认，红=错误/高风险，灰=已完成/已停止 |
| **流式透明** | Agent 的每一步思考、执行、结果都实时可见 | LLM 输出 token-by-token 流式渲染，工具执行有生命周期事件动画 |
| **暗色为本** | 开发者长时间使用，暗色模式是默认而非可选 | 默认 Dark Mode（OLED），Light Mode 作为后续可选项 |
| **可回溯** | 诊断是探索过程，用户需要随时回看历史 | 时间线布局，每步带时间戳，工具结果可展开回看 |

## 2. 色彩系统

### 语义色 Token

基于 Slate 深色基底，通过 CSS 变量 + shadcn/ui `@theme inline` 映射到 Tailwind v4。

| Token | Hex | 用途 |
|-------|-----|------|
| `--background` | `#0F172A` | 全局背景（Slate-950） |
| `--foreground` | `#F8FAFC` | 主文本（Slate-50） |
| `--card` | `#1B2336` | 卡片/面板背景 |
| `--card-foreground` | `#F8FAFC` | 卡片内文本 |
| `--primary` | `#1E293B` | 主操作面（Slate-800） |
| `--primary-foreground` | `#FFFFFF` | 主操作面文本 |
| `--secondary` | `#334155` | 次要操作面（Slate-700） |
| `--secondary-foreground` | `#FFFFFF` | 次要操作面文本 |
| `--muted` | `#272F42` | 静默背景（输入框、禁用区） |
| `--muted-foreground` | `#94A3B8` | 次要文本（Slate-400） |
| `--border` | `#475569` | 边框/分隔线（Slate-600） |
| `--accent` | `#22C55E` | 强调色：运行中/成功（Green-500） |
| `--accent-foreground` | `#0F172A` | 强调色上文本 |
| `--destructive` | `#EF4444` | 错误/高风险（Red-500） |
| `--ring` | `#FFFFFF` | 键盘焦点环 |

### 状态语义色

| 状态 | 颜色 | Token 映射 | 场景 |
|------|------|-----------|------|
| 运行中/成功 | 绿 `#22C55E` | `--accent` | Agent 正在思考、工具执行中、诊断完成 |
| 需确认 | 黄 `#EAB308` | `--warning` (自定义) | 低风险工具等待确认 |
| 高风险 | 红 `#EF4444` | `--destructive` | 高风险工具警告、错误、SSH 连接失败 |
| 已停止/已完成 | 灰 `#64748B` | `--muted-foreground` | Agent 已停止、历史会话 |
| 信息 | 蓝 `#3B82F6` | `--info` (自定义) | 中性提示、环境信息 |

### 对比度要求

| 元素 | 最低对比度 |
|------|-----------|
| 正文文本 | 4.5:1 |
| 大标题（≥18px bold） | 3:1 |
| 图标/非文本 UI | 3:1 |
| 焦点环 | 3:1 |
| 禁用状态 | 不要求，但需视觉可辨识 |

## 5. 组件设计

### 5.1 会话列表项

```
┌──────────────────────────┐
│ ● OOMService OOM 诊断     │  ← 状态点 + 标题
│   192.168.1.100 · 3步     │  ← 环境 + 进度
│   2 分钟前                 │  ← 时间
└──────────────────────────┘
```

- 状态点：绿(运行) / 灰(停止) / 黄(待确认) / 红(错误)
- 选中项：左侧 2px 绿色边条 + 背景提亮

### 5.2 Agent 思考流

- 逐 token 流式渲染（typewriter 效果），不用 spinner 等待完整响应
- 思考文本用 `JetBrains Mono`，`--muted-foreground` 色，区别于最终结论
- 最终结论用 `IBM Plex Sans`，`--foreground` 色，加粗

### 5.3 工具执行卡片

```
┌─────────────────────────────────────────────────┐
│ ▸ [jstat] -gc 12345 1000 5          ✓ 1.2s     │  ← 折叠态
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ▾ [jstat] -gc 12345 1000 5          ✓ 1.2s     │  ← 展开态
│   ┌─────────────────────────────────────────┐   │
│   │  S0C    S1C    ...  YGC   FGC  GCT      │   │
│   │  2048.0 2048.0 ...  12    0    0.234    │   │  ← 结构化输出
│   └─────────────────────────────────────────┘   │
│   [复制] [用作上下文]                             │
└─────────────────────────────────────────────────┘
```

- 工具名用 `JetBrains Mono`，绿色 badge
- 执行中：badge 显示 spinner + "执行中..."
- 成功：✓ + 耗时
- 失败：✗ + 错误摘要，展开看详情
- 输出区：等宽字体，可折叠，支持复制

### 5.4 确认请求卡片

**低风险（黄色边条）：**
```
┌─────────────────────────────────────────────────┐
││ ⚠ 需要确认: arthas trace                        │
││ 将注入字节码到目标 JVM，可能影响性能             │
││ [确认执行]  [拒绝]                              │
└─────────────────────────────────────────────────┘
```

**高风险（红色边条 + 警告底色）：**
```
┌─────────────────────────────────────────────────┐
││ ⚠⚠ 高风险操作: jmap -dump                      │
││ 此操作将触发 Full GC (STW)，可能导致服务暂停    │
││ 目标: 192.168.1.100 PID 12345                  │
││ [我已了解风险，确认执行]  [拒绝]                │
└─────────────────────────────────────────────────┘
```

### 5.5 输入框

- 底部固定，多行可展开
- Agent 运行时输入框提示"补充信息..."，发送后会追加到会话
- Agent 停止后提示"重新描述问题或补充信息..."
- 支持 `Shift+Enter` 换行，`Enter` 发送

### 5.6 状态指示器

| 状态 | 视觉 | 位置 |
|------|------|------|
| Agent 运行中 | 绿色脉冲点 + "诊断中" | 顶栏右侧 |
| Agent 已停止 | 灰色静态点 + "已停止" | 顶栏右侧 |
| 待确认 | 黄色闪烁点 + "待确认" | 顶栏右侧 |
| 连接中 | 蓝色 spinner + "连接环境" | 顶栏右侧 |
| 连接失败 | 红色点 + "连接失败" | 顶栏右侧 |

## 7. 数据可视化

### 7.1 实时流式图表

用于展示 jstat、GC 指标等实时采集的数据。

| 场景 | 图表类型 | 说明 |
|------|---------|------|
| GC 次数/耗时趋势 | Streaming Area Chart | 实时更新，保留最近 60-300s |
| Heap 各代占用 | 分层面积图 | Eden/Survivor/Old/Perm 分层 |
| 异常标记 | Line Chart with Highlights | 异常点用红色圆点 + 文本注释 |

**颜色约定**：
- 当前值脉冲：`#22C55E`（绿）
- 历史数据：渐变透明度（越旧越淡）
- 异常标记：`#EF4444`（红圆点 + 填充）
- 网格线：`--border` 低透明度

**无障碍**：
- 不依赖颜色 alone——异常点同时用形状（圆点）和文本注释
- 提供 Pause/Resume 按钮控制流式更新
- 键盘焦点可查看具体数据点值
- 支持 `prefers-reduced-motion`：停止流式动画，改为静态最新值

### 7.2 诊断结果摘要

用 Bullet Chart 展示关键指标 vs 健康阈值：

```
Heap 使用率    [████████████░░░░░░] 78%  阈值 85%
GC 频率       [██████░░░░░░░░░░░░] 32%  阈值 60%
线程数        [████████████████░░] 89%  阈值 90%  ⚠
```

- 正常范围：绿色条
- 接近阈值：黄色条
- 超过阈值：红色条 + ⚠ 标记

## 8. 交互模式

### 8.1 流式输出

- Agent LLM 输出逐 token 渲染（typewriter 效果），不用 spinner 等待完整响应
- 工具执行时显示 "执行中..." + spinner，完成后展示耗时
- 长时间操作（>3s）显示进度条或步骤指示器

### 8.2 进度反馈

| 操作时长 | 反馈方式 |
|---------|---------|
| < 200ms | 无反馈（感知不到延迟） |
| 200ms - 1s | Spinner / 骨架屏 |
| 1s - 3s | Spinner + 文字说明（"正在连接 192.168.1.100..."） |
| > 3s | 步骤指示器（"步骤 2/4: 正在采集 GC 数据"） |

### 8.3 动画

| 场景 | 动画 | 时长 |
|------|------|------|
| 卡片展开/折叠 | height + opacity | 200ms ease-out |
| 状态点脉冲 | opacity 0.5↔1.0 | 1.5s infinite |
| 新消息进入 | translateY(8px→0) + opacity | 250ms ease-out |
| 确认卡片出现 | scale(0.95→1) + opacity | 200ms ease-out |
| 焦点环 | box-shadow transition | 150ms |

- 所有动画尊重 `prefers-reduced-motion`：禁用动画，直接显示最终状态
- 动画时长统一用 Token：`--duration-fast` (150ms)、`--duration-normal` (250ms)、`--duration-slow` (400ms)
- 缓动函数：`--ease-out` (cubic-bezier(0.16, 1, 0.3, 1))

### 8.4 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+N` | 新建诊断会话 |
| `Ctrl+K` | 快速搜索历史会话 |
| `Ctrl+Enter` | 发送补充信息 |
| `Ctrl+.` | 停止 Agent |
| `Ctrl+Shift+C` | 复制最后工具输出 |
| `Esc` | 关闭确认卡片 / 取消焦点 |

## 9. 技术实现约定

### 9.1 技术栈

| 层 | 技术 |
|----|------|
| 组件库 | shadcn/ui (基于 Radix UI) |
| 样式 | Tailwind CSS v4 |
| 图标 | `@phosphor-icons/react` |
| 图表 | 自定义 SVG / Canvas（轻量场景）或 Recharts（复杂图表） |
| 字体 | JetBrains Mono + IBM Plex Sans (Google Fonts) |

### 9.2 shadcn/ui 主题约定

- 使用 CSS 变量（OKLCH）定义语义色，通过 `@theme inline` 映射到 Tailwind v4
- 不在组件中硬编码颜色——所有颜色走 `bg-primary`、`text-muted-foreground` 等 token
- 图表颜色通过 `chartConfig` 统一定义，不在组件内 inline

### 9.3 禁止项

- 不用 emoji 作为结构性图标（用 Phosphor SVG 图标）
- 不用 `bg-blue-500` 等硬编码颜色类
- 不用 raster PNG 图标（用 SVG）
- 不在同一视觉层级混用 filled 和 outline 图标
- 不用 `<div onClick>` 作为交互控件（用语义化 `<button>` 或 Radix primitive）
